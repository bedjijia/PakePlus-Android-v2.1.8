# 学校自动打铃系统

一个基于Web技术开发的自动打铃软件，用于模拟学校广播系统，支持自定义上下课铃声和时间安排。

## 功能特点

1. **后台/前台运行模式**：支持在后台持续运行，不影响其他工作
2. **配置文件导入导出**：支持保存和加载打铃时间表配置
3. **自定义铃声**：支持上传自定义MP3格式的上下课铃声
4. **区分上下课铃**：上下课铃声可以分开设置，支持不同的音频文件
5. **可视化时间表编辑**：直观的界面编辑上下课时间
6. **系统托盘功能**：最小化到系统托盘，随时可访问
7. **实时时间显示**：显示当前时间和距离下次打铃的时间
8. **通知提醒**：打铃时显示通知提醒

## 如何使用

### 直接使用

1. 下载项目文件
2. 用浏览器打开 `index.html` 文件即可运行

### 本地服务器运行（推荐）

为了获得最佳体验，建议使用本地服务器运行：

1. 安装Node.js
2. 安装http-server：`npm install -g http-server`
3. 在项目目录下运行：`http-server`
4. 在浏览器中访问提示的地址（通常是 http://localhost:8080）

## 功能说明

### 时间表设置

- **添加时间点**：点击"添加时间点"按钮，设置时间、铃声类型和名称
- **编辑时间点**：点击时间点右侧的编辑图标进行修改
- **删除时间点**：点击时间点右侧的删除图标进行删除

### 铃声设置

- **选择铃声**：点击"选择铃声"按钮上传自定义MP3文件
- **预览铃声**：点击播放图标预览铃声效果
- **重置铃声**：点击"重置"按钮恢复默认铃声
- **音量控制**：通过滑块调整铃声音量

### 系统选项

- **导入配置**：导入之前保存的JSON配置文件
- **导出配置**：将当前配置导出为JSON文件
- **打铃功能**：开关打铃功能
- **声音输出**：开关声音输出
- **后台运行**：启用后程序将在后台持续运行

### 系统托盘

- 点击"最小化"按钮将程序最小化到系统托盘
- 点击托盘图标显示菜单
- 可从托盘菜单快速显示窗口、切换打铃状态或退出程序
